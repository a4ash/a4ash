### ── what i'm building ─────────────────────────────

**[Prompt Injection Classifier](https://github.com/a4ash/prompt-injection-classifier)** · python, pytorch, hugging face, distilbert, scikit-learn

Fine-tuned a DistilBERT model to detect LLM prompt-injection attacks at **0.988 F1**, beating the best classical baseline (0.972) by catching paraphrased and obfuscated attacks that keyword filters miss. Built a leakage-safe dataset from multiple public sources (correcting inflated scores from a naive split) and mapped failure modes to **OWASP LLM01**. Open-source, with the trained model published to the [Hugging Face Hub](https://huggingface.co/A4Ash/prompt-injection-distilbert).
