**ML + Security** · Software Development & Network Engineering @ Sheridan College · Oakville, ON

I build and break ML systems — right now I'm focused on the security side of LLMs.

### ── what i'm building ─────────────────────────────

**[Prompt Injection Classifier](https://github.com/a4ash/prompt-injection-classifier)** — Fine-tuned a DistilBERT model to detect LLM prompt-injection attacks at **0.988 F1**, beating the best classical baseline (0.972) by catching paraphrased and obfuscated attacks that keyword filters miss. Built a leakage-safe dataset from multiple public sources (correcting inflated scores from a naive split) and mapped failure modes to **OWASP LLM01**. Open-source, with the trained model published to the [Hugging Face Hub](https://huggingface.co/A4Ash/prompt-injection-distilbert).

**LLM Red-Teaming Scanner** _(in progress)_ — Automated red-teaming of LLMs with `garak`: running promptinject probes against live models, analyzing hits, and working toward contributions back to the OSS project.

**[Song Popularity Predictor](https://github.com/a4ash)** — Engineered features from a 32K-song, 6-genre Spotify dataset, compared Linear Regression vs. Random Forest, and deployed the trained model as a RESTful web app validated end-to-end against live Spotify tracks.

**Roleplay Discord Bot** _(in progress)_ — Event-driven `Discord.py` bot that automates role management and integrates external REST APIs to power character creation, dice rolling, and an in-server player economy.
